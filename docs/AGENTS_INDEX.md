# AGENTS do repositório

Este arquivo é um mapa de escopo. Ele não substitui nem replica as instruções
dos `AGENTS.md`.

## `/AGENTS.md`

Aplica-se ao projeto inteiro. Contém as regras gerais do SIA/MEB, invariantes
de segurança e arquitetura, fluxo Git, validações e orientação de contexto.
Deve ser lido antes dos guias específicos aplicáveis.

## `/backend/AGENTS.md`

Aplica-se ao diretório `backend/`. Consulte-o para tarefas envolvendo Django,
DRF, models, migrations, services, permissions, dados, legado ou testes
backend.

## `/frontend/AGENTS.md`

Aplica-se ao diretório `frontend/`. Consulte-o para tarefas envolvendo
Next.js, React, BFF, autenticação no browser, contratos de apresentação, UI ou
testes frontend.

## Roteamento documental

Depois de aplicar os AGENTS pertinentes, use [[00_HOME]] para selecionar
somente a documentação necessária à tarefa atual.
